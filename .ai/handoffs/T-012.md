   - Verified that fork deep merge/dict preservation retains unknown keys across save/load cycles.
3. Rollback safety:
   - If rolling back from a future 1.7.4.1 image to 1.7.2.1:
     - `usage/logs.sqlite3` is simply ignored by 1.7.2.1 (it does not read or lock the file).
     - Extra settings keys in `settings.json` are preserved or ignored without errors.
     - Rollback remains image-only safe.
4. SQLite log persistence:
   - By default (`log_db_enabled=False`), no `logs.sqlite3` file is created and logs remain exclusively in-memory.
   - When enabled, writes go to `usage/logs.sqlite3`, bounded by default 7-day retention and configurable row/byte caps.
   - Git ignores `usage/*.sqlite3*`.
5. POSIX credential hardening:
   - `wb_agents.py` uses `WRITE_MODE = 0o600` via `os.open(..., O_CREAT, 0o600)`. On POSIX systems, config/credential files are created owner-only. On Windows, standard NTFS ACLs apply without crashing.
